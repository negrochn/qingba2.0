# 庆爸听力线 2.0

一个帮助家长记录孩子英语听力训练打卡进度的小程序，基于「庆爸听力线 常规路径（2.0版）」路线设计。

## 功能概览

### 首页（打卡概览）

- 2×2 网格展示四项核心数据：本周时长、累计时长、常规X 阶段、已读完次数
- 点击各格子可跳转到对应的统计详情页
- 展示当前阶段打卡记录

### 路线

- 7 个阶段可视化路线图：常规 1-6 阶段 + 准桥梁阶段
- 当前阶段可打卡，已完成阶段显示绿色 ✓，未解锁阶段显示 🔒
- 点击阶段进入详情页，查看该阶段的资源列表

### 阶段详情

- 展示阶段内所有绘本/动画/音频资源
- 点击资源打开打卡弹窗，记录学习时长
- 已读完的绘本标记完成状态

### 时长统计

- 周 / 月 / 年 / 全部 四个维度切换
- 柱状图展示各时间段的打卡时长
- 支持横向滑动查看更多数据
- 顶部数据卡片展示汇总信息

### 阶段时长

- 按阶段统计累计打卡时长
- 柱状图展示各阶段投入时间

### 已读完统计

- 按阶段统计绘本已读完次数
- 柱状图展示各阶段完成次数

### 设置

- 数据备份：生成 .txt 备份文件，转发给微信好友或文件传输助手
- 数据导入：从微信聊天记录中选择备份文件恢复
- 数据清空：清除所有打卡记录

## 技术栈

- **框架**：微信小程序原生开发
- **图表**：wxCharts（canvas 柱状图）
- **数据存储**：wx.getStorageSync / wx.setStorageSync
- **文件操作**：wx.getFileSystemManager / wx.shareFileMessage

## 路线数据

路线基于「庆爸听力线 常规路径（2.0版）」，适用于 3-4 岁儿童英语听力训练，共 7 个阶段：

| 阶段 | 时间投入建议 | 准入标准 |
|------|-------------|---------|
| 常规一 | 60-80H | 零基础 |
| 常规二 | 60-80H | phase5 |
| 常规三 | 60-80H | phase8 |
| 常规四 | 60H | phase12 |
| 常规五 | 60H | phase14 |
| 常规六 | 60H | phase16 |
| 准桥梁 | 80-100H | 佩奇可初步裸听 |

## 本地开发

1. 安装 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)
2. 克隆本仓库
3. 在开发者工具中导入项目，选择项目根目录
4. AppID 填写自己的测试号（或点击"使用测试号"）
5. 编译运行

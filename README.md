# 庆爸听力线 2.0

一个帮助家长记录孩子英语听力训练打卡进度的小程序，内置**常规路线**（3-4 岁 · 7 阶段）与**大循环路线**（9 阶段）两条路线：可随时切换，打卡 / 统计 / 资源按路线隔离；走完一条路线的主链终点后，首页切换为毕业庆祝卡。

完整更新历史见 [CHANGELOG.md](./CHANGELOG.md)。

## 功能概览

### 首页（打卡概览）

- 顶部欢迎条：英文日期 + 时段问候，后跟 `Day N`（当前阶段从首次打卡到今天的天数；首次当天为 Day 1，跨阶段自动重新计数，今天未打卡也照常计数）
- 本周 Hero 卡：本周时长 + 周环比 + 周一至周日柱状图
- 2×2 指标网格：今日时长、今日打卡、阶段时长、连续打卡（前两格可点开明细，后两格箭头为装饰）
- 「今日时长」「今日打卡」可点击：从底部升起**今日明细弹窗**（两卡共用同一面板，分别按时长 / 次数降序展示今天打过卡的绘本，带每本占比条与汇总），口径与卡片数字严格一致；时长显示为「X小时Y分钟」，与统计页时长排行榜一致
- **未设置阶段时**：Hero 卡与 2×2 整体隐藏，改为欢迎卡引导（「欢迎使用庆爸2.0」+ 路线说明 + 「选择当前阶段」按钮直达阶段选择页 + 一句「所有阶段均已开放，时间投入到位即可进入下一阶段」），避免新用户一进来看到满屏 0
- **毕业态**：当前阶段是主链终点且已被显式标记完成（点过「完成阶段」）时，首页切换为**毕业庆祝卡**——品牌绿徽章 + confetti 散点、按路线区分的庆祝标题（如「大循环路线圆满收官」）与全程口径三联数字（天陪伴 / 小时累计 / 天打卡），顶部问候切「Congratulations, Day N」（N = 全程陪伴天数），顶部右侧阶段名与百分比隐藏。判定纯运行时计算：老用户零迁移自动生效，切走复习自动失效；**毕业 ≠ 停止记录**——今日 / 本周数据与打卡入口保留，自由听读照常打卡

### 路线

- **双路线**：常规路线（常规 1-6 + 准桥梁，共 7 阶段）与大循环路线（前置、一阶段、3 条可选调整支线、标准牛4-6、三阶段牛7-9，共 9 阶段）；设置页「切换路线」进入整页单选（`pages/routePicker`），切换时提示「数据按路线隔离」——两条路线的当前阶段 / 打卡 / 统计互不干扰
- 当前路线的阶段可视化路线图：WeUI 时间线列表，右侧 44rpx 圆节点由 1px 竖线串联，四态用 iconfont 图标区分（当前 = `icon-right` 右箭头 / 已完成 = `icon-check` 品牌绿对勾 / 未解锁 = `icon-lock` 灰色锁 / 未设置起点 = 无图标的中性描边空圈），每行含阶段名、phase 与词汇 / 时长目标、进入与晋级条件
- **可选支线**：大循环的「调整·牛1-3」为可选支线（无时长目标、不占主线晋级链），路线页带「可选支线」徽标、进度显示「—」；切入点看测试结果，由家长在阶段选择页自行切换
- 「当前阶段」整行浅绿底高亮，与已完成 / 未解锁拉开层级
- 顶部「当前阶段」入口：分组标题下单个 cell，右侧显示该阶段进度百分比（无时长目标的支线显示「—」），阶段名下方显示当前目标（如「目标 80H」）；与阶段详情页同一套晋级口径，分母可在「设置 → 阶段目标时长」调整，点击直达详情；毕业态下该入口整块隐藏
- 仅当前阶段可打卡与晋级；已完成 / 未解锁阶段只读，点击进入详情查看资源
- 未设置当前阶段时：顶部「当前阶段」显示「未设置 · 选择一个阶段作为起点」，点右侧「去选择」直达选择页；下方全部阶段为空圈待选态（不显示锁）

### 阶段详情

- 展示阶段内所有绘本 / 动画 / 音频资源，按该阶段**实际包含的分组**展示并支持折叠（常规1-5 为 7 类，常规6 / 准桥梁为 8 类——多「科普拓展」；开启「熏听」后再各多一类）
- 资源列表合并官方资源与「我的资源」（自定义资源带「自定义」标记，排在官方资源之后）
- 点击资源打开打卡弹窗：填学习时长（含 10 / 15 / 20 / 25 / 30 快捷分段）+ 备注（按资源记住上次填写，下次自动带出）
- 资源行左滑「读完 / 撤销」标记完成次数：滑开一行自动收起其他行，行内左侧方块兼作已读次数徽标（0 次回落为资源名首字）；弹窗里不再有「已读完」入口，分组头也不再显示「已读 N」合计
- **阶段晋级**：当前常规阶段展示进度填充按钮，上方显示「已投入 12.5h / 目标 80h」，时间达标后可晋级（未达标点击会提示还需时长）；分母默认取建议区间上限，可在「设置 → 阶段目标时长」按阶段调整。开启「小小优趣计划」时需输入测试结果达到目标 phase 才能晋级
- **可选支线可打卡**：未走过的调整支线（大循环）状态为「可选」而非锁定——正常浏览资源与打卡，分组标题旁带「可选支线」徽标；数据保留，进度不计入主线
- **关键要点折叠**：要点 ≤3 条全展开；更多时默认只显前 2 条，底部渐隐 + 「展开全部 N 条 / 收起」，整块连续段落卡呈现（大循环前置阶段 8 条长要点不再挤压打卡主流程）

### 熏听

- **入口在设置页「学习设置 → 熏听」**（默认关闭）：开启后各阶段页多出一个「熏听」分组，可打卡、可左滑标记读完；关闭后该分组隐藏（已挂进去的自定义资源不删除，重新开启即恢复）
- **官方数据里没有熏听素材**：该分组只作占位，内容由家长在「我的资源」里自己添加（如「牛津树L3 熏听」）；建议命名带「熏听」二字，便于与主线素材区分
- **时长按阶段系数折算为「有效时长」**（对齐 about 页的时间计算：牛1-2 可听但不计入、牛3 ×0.5、牛4 及以后 ×0.8；阶段依据是该阶段主线里的牛津树级别 —— 常规N ↔ 牛N）：

| 阶段 | 常规1 / 常规2 | 常规3 | 常规4 · 常规5 · 常规6 · 准桥梁 |
| --- | --- | --- | --- |
| 系数 | ×0（可记录，不计入） | ×0.5 | ×0.8 |

- **折算只改统计口径，不改原始记录**：记录里同时存原始时长与系数（`factor`，老记录缺省视为 1）；阶段进度、首页与统计页时长、晋级判定一律用「原始 × 系数」
- **阶段页是「打卡视图」，按原始投入展示**：资源行徽标与「今日已打卡 X 分钟」显示的是家长实际投入的时长，熏听行再补一句「有效 24 分钟」（常规1/2 显示「本阶段不计入」）—— 这样 ×0 档也能看见「今天听过」，不会因有效时长为 0 被当成没打卡
- 首页今日明细的**时长**榜与统计页时长排行榜只列有效时长大于 0 的素材（×0 的熏听不会以「0分钟」出现在榜里；次数榜照常记录）
- 打卡弹窗 / 补录 / 编辑页都会实时显示折算说明（如「60 分钟计 48 分钟」）；编辑记录时若改了阶段或分组，系数按新阶段 + 新分组自动重算
- **打卡记录页**：熏听记录在时长后跟一个折算标记（`×0.5` / `×0.8` / `不计入`），与打卡弹窗单位旁的标记同套语汇、同档字号；折算后的具体数值不在这页展开（那是统计与进度的口径）

### 我的资源

- 入口在设置页「学习设置」组，右侧显示当前自定义资源数量
- 列表始终列出**全部**自定义资源：被开关隐藏的分组（如熏听开关关闭时的「熏听」组）也会列出并标「已隐藏」，不会出现「计数有 N 项、点进去空白」
- 把自己买的书 / 动画加进来，归入某个阶段下已有的分组（如「常规2 · 主线分级」）
- 新增 / 改名 / 改归属（换阶段 + 换分组）走半屏弹窗：归属是「阶段」「分组」两行原生选择器、**联动**（切阶段会重建分组列表，各阶段的分组集合不同），删除为列表左滑 + 二次确认；改名与改归属时历史打卡记录、已读次数、默认备注一起迁移
- 删除资源只移出清单，已产生的打卡记录与统计保留
- 约束：名称 1~20 字、不能包含 `|`、同阶段同分组不可同名、每阶段最多 50 个；只能挂在官方数据里已存在的分组下
- 自定义资源与官方资源完全同权：参与打卡、今日时长、阶段进度与晋级判定，也计入统计页的时长 / 读完排行榜

### 打卡记录

- 按年 / 月筛选查看历史打卡记录（月份选择器为原生年月选择器，范围锁在「今年 -3 年 1 月」~「当前月」，不可选未来）
- 展示阶段、分组、时长、备注与「补录」等标签（熏听记录在时长后跟一个折算标记：`×0.5` / `×0.8` / `不计入`）
- 支持左滑**编辑 / 删除**：两条操作左滑露出，非破坏的「编辑」在左、「删除」在右；编辑跳到独立编辑页（`pages/editRecord`），整页只有一块 cells——日期 / 阶段用原生选择器，「资源」一行内用两列联动选择器（左分组 / 右资源，分组名显示在资源名下方），再加时长 / 备注，全部可改（记录 id 不变，跨月改日期时列表自动切到目标月份）
- 支持**补录**：头部「补录」入口 → **一次补「一天」的多条**，在同一屏里把当天读过的几本一次填完、一次提交（取代原先「一本书进一次页面」的往返）。日期与阶段用原生选择器（日期上限锁今天），每行点资源名弹出双列选择弹层（左分组 / 右资源，自动定位到该资源所属分组并记住上次选的分组；弹层高度按分组数自动取 7 / 8 / 9 行三档，左列一屏铺满、不出滚动条）、选中后键盘自动落到该行时长框，「＋ 添加一条」新行直接弹选择器、行尾 `✕` 删除；补录数据计入阶段时长、统计与晋级判定，列表记录带「补录」标记，提交后自动切到补录月份

### 我的

- 打卡记录、数据统计、路线介绍、设置入口（左侧为 iconfont 功能图标，右侧统一 `icon-right` 箭头）
- 路线介绍只显示**当前路线**的入口（常规 / 大循环二选一，切换路线后自动跟随）；介绍页为文章式页面，可分享给好友与朋友圈

### 数据统计

- 单页结构：原「统计总览（阶段列表）→ 阶段统计详情」两级已合并为一页，进入即为某个阶段的累计统计，返回一次即回「我的」；统计口径跟随**当前路线**（切路线后看到的是该路线的数据）
- 顶部左侧「阶段选择器」：原生选择器（与补录 / 编辑页的阶段选择同款），列出当前路线的全部阶段；默认选中当前阶段（未设置时取第一个有数据的阶段）
- 内容（ECharts 图表 + 纯 CSS 列表）：
  - 累计时长：以「X 小时 Y 分钟」大数字扁平展示（无卡片）
  - 阶段跨度：首次打卡日 → 最后打卡日，并显示「阶段名称 历时 N 天」
  - 汇总三项：打卡次数 / 打卡天数 / 读完次数（简单 flex，前两项一行、第三项换行，每项右侧 `icon-right` 箭头）
  - 打卡时长分布：竖向柱状图（ECharts），触摸可查看各周期时长
  - 分组时长对比：雷达图（ECharts），**轴按当前阶段实际分组动态生成**（常规1-5 为 7 轴、常规6 / 准桥梁为 8 轴，开启熏听各多一轴；同时并入记录里出现过的分组，避免旧数据「有数据没轴」），无数据的分组保留为 0
  - 时长排行榜 / 读完排行榜：按阶段素材的累计时长 / 读完次数降序，行内「首字图 + 名称 + 数值」，淡绿占比条（分母为该阶段累计时长 / 累计读完次数，各行相加为 100%；时长文案为「X小时Y分钟」）
  - 该阶段无任何打卡记录时显示整页空态

### 设置

设置页采用微信原生分组列表风格，所有选择类入口统一跳转整页单选页（原语3）。

字号与深色模式**不设页内开关**，直接跟随微信设置（没有变化监听 API，靠各页 `onShow` 重新读取，改完设置切回小程序即生效）：

- **字体大小**：跟随「微信 > 我 > 设置 > 通用 > 字体大小」，按缩放倍率归并到四档 `--fs`（`fs-small` / `fs-normal` / `fs-large` / `fs-xlarge`），全站正文即时缩放（40rpx 以下的正文类字号生效，超大标题与装饰元素保持不变）
- **深色模式**：完全跟随微信 / 系统主题，页面背景、卡片、文字、导航栏与 tabBar 自动适配（导航栏与 tabBar 由 `app.json` 的 `darkmode` + `theme.json` 渲染，内容区固定挂 `dm-auto`）

> 两者都不再提供小程序内手动切换。深色若允许手动，会出现「导航栏（框架级、只跟系统）与内容区（跟手动档）」的割裂；字号则因为 `rpx` 不随系统字号缩放，只能主动读微信的 `fontSizeSetting` / `fontSizeScaleFactor` 再映射。

- **学习设置**
  - 切换路线：整页单选（原语3）在常规路线 / 大循环路线间切换；数据按路线隔离，切换后阶段选择、打卡、统计、备份清空均针对当前路线
  - 当前阶段：整页单选（原语3）选择/修改当前学习阶段；切换时该阶段沿晋级链的所有前序阶段自动标记为已完成（大循环分叉下只标链上前序，不误标可选支线）
  - 阶段目标时长：设置进度百分比与晋级判定的分母。默认档位取建议区间**上限**（60-80H 按 80H），也可逐阶段填自定义小时数（绝对值、不随档位联动，可一键恢复默认）
  - 我的资源：跳转自定义资源管理页（新增 / 改名 / 改归属 / 删除）
  - 小小优趣成长计划：默认开启；开启后完成阶段需校验测试结果
  - 熏听：默认关闭；开启后阶段页显示「熏听」分组，时长按阶段系数折算为有效时长（见「熏听」一节）
- **数据管理**
  - 导出备份：一键生成 .docx（Word）备份文件并打开预览
  - 导入备份：整页单选（原语3）选择导入方式（覆盖式 / 合并式）后，从微信聊天选择备份文件恢复，支持 txt / json / docx
  - 清空数据：整页单选（原语3）选择清空范围（「全部数据」，或单独清某一个阶段），二次确认后执行；按阶段清空会连同该阶段的打卡记录、已读次数、默认备注与已完成标记一起清除
- **开发者工具（仅开发版）**
  - 压力测试：按各阶段官方时长目标生成模拟打卡数据（区间目标在区间内随机、单值固定、80H+ 取下限；大循环调整支线按「试走量」12-20 小时生成并保持未完成），每日 15-60 分钟、含缺卡日
- **关于**
  - 关于小程序：正式版显示「版本X.X.X」；开发版 / 体验版 / 取不到版本号时只显示「开发版 / 体验版 / 未知版本」（不做假版本号兜底）
  - 数据存储：本地存储

### 关于

- 两个文章式路线介绍页：**常规路线介绍**（`pages/about`：使用说明、路线介绍与「阶段参考」，7 个阶段的准入标准 / 晋级参考逐条列出）与**大循环路线介绍**（`pages/about-bigloop`：9 阶段逐阶段素材与要点、目标与达标判断）
- 页内不设分享按钮，转发走右上角菜单

### 分享

- 文案与落地路径集中在 `utils/share.js`，各页只声明自己的场景 key
- **落地页统一为首页**：好友点开就是「欢迎卡 + 选择当前阶段」，不必先读一屏说明；也不会把统计 / 记录这类私人数据页当落地页
- **标题按场景定制**：首页带当前累计时长（如「陪孩子练英语听力，已累计 12.5 小时」）、阶段页带当前阶段名，路线 / 记录 / 统计各有专属文案，其余页用统一兜底标题
- **分享到朋友圈只对两个路线介绍页开放**（常规 / 大循环）：官方要求页面同时声明「发送给朋友」+「分享到朋友圈」才可被分享，且朋友圈打开的是**单页模式**（无 tabBar、页面不能跳转、`button open-type` 被禁用）；只有纯内容页不会出现点了没反应的死链，故其它页不实现 `onShareTimeline`
- **从分享进入不展示封面广告**：转发路径统一追加 `isShowSplashAd=false`（`utils/share.js` 的 `_withoutSplashAd()`，已有 query 用 `&` 拼接、已带该参数不重复追加），新用户点开分享卡片第一眼是首页欢迎卡而不是开屏广告。官方限制：仅对支持自定义路径的场景生效（单聊 / 群聊消息卡片），需安卓微信 8.0.37+ / iOS 8.0.40+ / 基础库 2.32.3+，旧客户端仍可能展示；未开通封面广告时该参数无害

## 技术栈

- **框架**：微信小程序原生开发，无构建步骤；无后端，数据全部存在本地
- **数据存储**：wx.getStorageSync / wx.setStorageSync（按月分片存储，含存储空间预警与两阶段写入回滚）
- **文件操作**：wx.getFileSystemManager / wx.openDocument（导出 .docx 备份，导入 txt / json / docx）
- **图表**：ECharts（按需构建，仅引入柱状图 / 雷达图，页面级集成，无需自定义组件）
- **图标**：iconfont —— 字形类抽到 `styles/iconfont.wxss`，字族以 base64 data URI 在 `app.wxss` 内联注册（跨页面生效）；更新字体后跑 `scripts/gen_iconfont_base64.ps1` 重新生成
- **版本更新**：接入 `wx.getUpdateManager()`，新版本就绪时提示重启（不清本地数据）

## 本地开发

1. 安装 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)
2. 克隆本仓库
3. 在开发者工具中导入项目，选择项目根目录
4. AppID 填写自己的测试号（或点击"使用测试号"）
5. 编译运行

### 关于 AppID（真实 appid 不入库）

`project.config.json` 中的 `appid` 固定为 `touristappid`（游客态），仓库**不存放真实 AppID**。在开发者工具里填写自己的 AppID 后，工具会把它写回这个文件，为避免误提交、泄露真实 AppID，建议在本机对该文件加标记：

```bash
git update-index --skip-worktree project.config.json   # 加标记（撤销：--no-skip-worktree）
```

- 这是**本地**设置（存于 `.git/info/index`），不会随仓库分发 —— 换机器 / 重新 clone 后需再执行一次
- 加标记后 `git add` 会**静默忽略**该文件的改动；若确实要改它受版本控制的内容（如 `packOptions.ignore`），先撤销标记，改完提交后再加回来
- 个人编译设置存放于 `project.private.config.json`，该文件已在 `.gitignore` 中，不受影响

# 庆爸听力线 2.0

一个帮助家长记录孩子英语听力训练打卡进度的小程序，基于「庆爸听力线 常规路径（2.0版）」路线设计。

> **v3.0.0 全新布局**：设置页与全部选择类交互重构为微信原生分组列表 + 整页单选（原语3）风格，统一配色、字号、间距与深色模式适配，并沉淀为 `ui-design-spec` 设计规范；新增「数据统计」模块，阶段统计详情接入 ECharts 柱状图 / 雷达图与素材排行榜。
>
> **v3.1.0**：支持「我的资源」——把自己买的书 / 动画加进来，归入现有 8 个分组之一，与官方资源一起参与打卡、统计与阶段晋级；官方资源完成 id 化，打卡数据 key 同步升级并自动迁移老数据。「数据统计」由两级合并为单页（顶部阶段选择器切换阶段）。
>
> **v3.2.0**：打卡记录页新增「补录」，可补记历史日期的打卡（日期 + 阶段/分组/资源三级级联 + 时长/备注）；阶段页资源行新增「读完 / 撤销」左滑操作，读完不再走打卡弹窗里的二级入口，分组头的「已读 N」因语义不清一并移除。
>
> **v3.3.0**：首页新增 **Day N**（当前阶段从首次打卡到今天的天数，断更也不归零），2×2「打卡天数」改为「连续打卡」；未设置阶段时首页显示欢迎卡引导（替代全 0 的统计），路线页不再满屏显示锁，顶部「当前阶段」可直接去选择起点。
>
> **v3.4.0**：首页「今日时长」「今日打卡」可点击查看**今日明细弹窗**（底部半屏，两卡共用面板、分别按时长与次数聚合）；统计页时长 / 读完排行榜的占比分母改为统计维度累计值，中文时长文案统一为 `checkin.fmtMinutesCN`；打卡记录左滑新增「编辑」，与「删除」并列，编辑复用补录页表单（日期 / 阶段 / 分组 / 资源 / 时长 / 备注全部可改）。另修复**深色模式下月份 / 阶段选择器弹层**的样式异常，并把全站分隔线 / 细边框统一改为 hairline 方案（解决真机上细线整条不可见、而开发者工具看不出来的问题）；另修复一批数据安全与稳定性问题（存储分片写失败回滚、补录与打卡重复提交、图表实例泄漏等），并清理零调用死代码。
>
> **v3.4.1**：新增分享能力：各页定制转发标题、落地页统一首页，「关于」页可分享给好友与朋友圈；「关于」页排版按 WeUI 规范重构（22pt 主标题、正文 17pt）；修复记录页标签不一致。
>
> **v3.5.0**：**字号与深色不再设小程序内手动档，改为完全跟随微信 / 系统** —— 字体大小读微信的 `fontSizeSetting` / `fontSizeScaleFactor` 映射到 `--fs` 四档，深色固定挂 `dm-auto`，内容区与 `theme.json` 渲染的导航栏 / tabBar 从此同源（设置页「显示」分组与字体大小 / 深色模式两个选择页一并移除）。**补录改为一次补「一天」的多条**：日期 + 阶段 + 当天多行，同一屏填完、一次提交；单条编辑拆为独立页 `pages/editRecord`，日期 / 阶段 / 资源改用原生 picker（分组 + 资源为两列联动），整页纵向瘦身约 320rpx。另把各页弹层关闭按钮统一为 iconfont `icon-close`（热区补足 88rpx），并补齐首页 / 我的资源 / 阶段页半屏面板的深色蒙层。

## 功能概览

### 首页（打卡概览）

- 顶部欢迎条：英文日期 + 时段问候，后跟 `Day N`（当前阶段从首次打卡到今天的天数；首次当天为 Day 1，跨阶段自动重新计数，今天未打卡也照常计数）
- 本周 Hero 卡：本周累计时长 + 周环比 + 周一至周日柱状图
- 2×2 指标网格：今日时长、今日打卡次数、阶段时长、连续打卡
- 「今日时长」「今日打卡」可点击：从底部升起**今日明细弹窗**（两卡共用同一面板，分别按时长 / 次数降序展示今天打过卡的绘本，带每本占比条与汇总），口径与卡片数字严格一致；时长显示为「X小时Y分钟」，与统计页时长排行榜一致
- **未设置阶段时**：Hero 卡与 2×2 整体隐藏，改为欢迎卡引导（「欢迎使用庆爸2.0」+ 路线说明 + 「选择当前阶段」按钮），避免新用户一进来看到满屏 0

### 路线

- 7 个阶段可视化路线图：常规 1-6 阶段 + 准桥梁阶段
- WeUI 时间线列表：右侧 44rpx 描边圆节点串联，四态用 iconfont 图标区分（当前 = 灰色右箭头 / 已完成 = 绿色对勾 / 未解锁 = 灰色锁 / 未设置起点 = 空圈），每行含阶段名、phase 与词汇/时长目标、进入与晋级条件
- 「当前阶段」整行浅绿底高亮，与已完成 / 未解锁拉开层级
- 顶部「当前阶段」入口：分组标题下单个 cell，右侧显示该阶段进度百分比（与阶段详情页同一套晋级口径），点击直达详情
- 当前阶段可打卡；节点图标区分四态（`icon-right` / `icon-check` / `icon-lock` / 空圈）
- 未设置当前阶段时：顶部「当前阶段」显示「未设置 · 选择一个阶段作为起点」，点右侧「去选择」直达选择页；下方 7 个阶段为空圈待选态（不显示锁）
- 点击阶段进入详情页，查看该阶段的资源列表

### 阶段详情

- 展示阶段内所有绘本/动画/音频资源，按 8 个分组展示，支持折叠
- 资源列表合并官方资源与「我的资源」（自定义资源带「自定义」标记，排在官方资源之后）
- 点击资源打开打卡弹窗，记录学习时长与备注
- 资源行左滑「读完 / 撤销」标记完成次数：滑开一行自动收起其他行，行内左侧方块兼作已读次数徽标（0 次回落为资源名首字）；弹窗里不再有「已读完」入口，分组头也不再显示「已读 N」合计
- **阶段晋级**：当前常规阶段展示投入进度，时间达标后可申请晋级；开启「小小优趣计划」时需输入测试结果达到目标 phase 才能晋级

### 我的资源

- 入口在设置页「学习设置」组，右侧显示当前自定义资源数量
- 把自己买的书 / 动画加进来，归入某个阶段下已有的分组（如「常规2 · 主线分级」）
- 支持新增 / 改名 / 改归属（换阶段 + 换分组）/ 删除；改名与改归属时历史打卡记录、已读次数、默认备注一起迁移
- 删除资源只移出清单，已产生的打卡记录与统计保留
- 约束：名称 1~20 字、不能包含 `|`、同阶段同分组不可同名、每阶段最多 50 个；只能挂在官方数据里已存在的分组下
- 自定义资源与官方资源完全同权：参与打卡、今日时长、阶段进度与晋级判定，也计入统计页的时长 / 读完排行榜

### 打卡记录

- 按年/月筛选查看历史打卡记录
- 展示阶段、分组、时长、备注等信息
- 支持左滑**编辑 / 删除**：编辑跳到独立编辑页（`pages/editRecord`），日期 / 阶段 / 分组 / 资源 / 时长 / 备注全部可改（记录 id 不变，跨月改日期时列表自动切到目标月份）；两条操作左滑露出，非破坏的「编辑」在左、「删除」在右
- 支持**补录**：头部「补录」入口 → **一次补「一天」的多条**，在同一屏里把当天读过的几本一次填完、一次提交（取代原先「一本书进一次页面」的往返）。日期与阶段用原生选择器（日期上限锁今天），每行点资源名弹出双列选择弹层（左分组 / 右资源，自动定位到该资源所属分组并记住上次选的分组；弹层高度按分组数自动取 7 / 8 / 9 行三档，左列一屏铺满、不出滚动条）、选中后键盘自动落到该行时长框，「＋ 添加一条」新行直接弹选择器、行尾 `✕` 删除；补录数据计入阶段时长、统计与晋级判定，列表记录带「补录」标记，提交后自动切到补录月份

### 我的

- 关于庆爸2.0、打卡记录、数据统计、设置入口（左侧为 iconfont 功能图标，右侧统一 `icon-right` 箭头）

### 数据统计

- 单页结构：原「统计总览（7 个阶段的列表）→ 阶段统计详情」两级已合并为一页，进入即为某个阶段的累计统计，返回一次即回「我的」
- 顶部左侧「阶段选择器」：点开为半屏滚轮弹层（与打卡记录页的月份选择器同原语），切换常规 1-6 / 准桥梁；默认选中当前阶段（未设置时取第一个有数据的阶段）
- 内容（ECharts 图表 + 纯 CSS 列表）：
  - 累计时长：以「X 小时 Y 分钟」大数字扁平展示（无卡片）
  - 阶段跨度：首次打卡日 → 最后打卡日，并显示「阶段名称 历时 N 天」
  - 汇总三项：打卡次数 / 打卡天数 / 读完次数（简单 flex 两列，右侧 `icon-right` 箭头）
  - 打卡时长分布：竖向柱状图（ECharts），触摸可查看各周期时长
  - 分组时长对比：雷达图（ECharts），固定展示 8 个分组轴（无数据也显示）
  - 时长排行榜 / 读完排行榜：按阶段素材的累计时长 / 读完次数降序，行内「首字图 + 名称 + 数值」，淡绿占比条（分母为该阶段累计时长 / 累计读完次数，各行相加为 100%；时长文案为「X小时Y分钟」）
  - 该阶段无任何打卡记录时显示整页空态

### 设置

设置页采用微信原生分组列表风格，所有选择类入口统一跳转整页单选页（原语3）。

字号与深色模式**不设页内开关**，直接跟随微信设置（没有变化监听 API，靠各页 `onShow` 重新读取，改完设置切回小程序即生效）：

- **字体大小**：跟随「微信 > 我 > 设置 > 通用 > 字体大小」，按缩放倍率归并到四档 `--fs`（`fs-small` / `fs-normal` / `fs-large` / `fs-xlarge`），全站正文即时缩放（40rpx 以下的正文类字号生效，超大标题与装饰元素保持不变）
- **深色模式**：完全跟随微信 / 系统主题，页面背景、卡片、文字、导航栏与 tabBar 自动适配（导航栏与 tabBar 由 `app.json` 的 `darkmode` + `theme.json` 渲染，内容区固定挂 `dm-auto`）

> 两者都不再提供小程序内手动切换。深色若允许手动，会出现「导航栏（框架级、只跟系统）与内容区（跟手动档）」的割裂；字号则因为 `rpx` 不随系统字号缩放，只能主动读微信的 `fontSizeSetting` / `fontSizeScaleFactor` 再映射。

- **学习设置**
  - 当前阶段：整页单选（原语3）选择/修改当前学习阶段；切换时该阶段之前的所有阶段自动标记为已完成
  - 我的资源：跳转自定义资源管理页（新增 / 改名 / 改归属 / 删除）
  - 小小优趣成长计划：默认开启；开启后完成阶段需校验测试结果
- **数据管理**
  - 导出备份：一键生成 .docx（Word）备份文件并打开预览
  - 导入备份：整页单选（原语3）选择导入方式（覆盖式 / 合并式）后，从微信聊天选择备份文件恢复，支持 txt / json / docx
  - 清空数据：整页单选（原语3）选择清空范围（全部数据 / 常规1-6 / 准桥梁），二次确认后执行；按阶段清空会连同该阶段的打卡记录、已读次数、默认备注与已完成标记一起清除
- **开发者工具（仅开发版）**
  - 压力测试：按真实计划生成测试数据（每阶段约 80-90 小时）
- **关于**
  - 关于小程序：显示「版本 X.X.X」
  - 数据存储：本地存储

### 关于

- 使用说明与路线介绍
- 底部「分享给好友」按钮（单页模式下隐藏）

### 分享

- 文案与落地路径集中在 `utils/share.js`，各页只声明自己的场景 key
- **落地页统一为首页**：好友点开就是「欢迎卡 + 选择当前阶段」，不必先读一屏说明；也不会把统计 / 记录这类私人数据页当落地页
- **标题按场景定制**：首页带当前累计时长（如「陪孩子练英语听力，已累计 12.5 小时」）、阶段页带当前阶段名，其余页为通用文案
- **分享到朋友圈只对「关于」页开放**：官方要求页面同时声明「发送给朋友」+「分享到朋友圈」才可被分享，且朋友圈打开的是**单页模式**（无 tabBar、页面不能跳转、`button open-type` 被禁用）；只有纯内容页不会出现点了没反应的死链，故其它页不实现 `onShareTimeline`，「关于」页在单页模式下也会隐藏分享按钮

## 技术栈

- **框架**：微信小程序原生开发
- **数据存储**：wx.getStorageSync / wx.setStorageSync（按月分片存储，含存储空间预警）
- **文件操作**：wx.getFileSystemManager / wx.openDocument
- **图表**：ECharts（按需构建，仅引入柱状图 / 雷达图，页面级集成，无需自定义组件）

## 路线数据

路线基于「庆爸听力线 常规路径（2.0版）」，适用于 3-4 岁儿童英语听力训练，共 7 个阶段：

| 阶段 | 时间投入建议 | 准入标准 |
|------|-------------|---------|
| 常规一 | 60-80H | 零基础 |
| 常规二 | 60-80H | phase5 |
| 常规三 | 60-80H | phase8 |
| 常规四 | 60H | phase12 |
| 常规五 | 60H | phase14 |
| 常规六 | 60H | phase16 |
| 准桥梁 | 80-100H | 佩奇可初步裸听 |

## 本地开发

1. 安装 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)
2. 克隆本仓库
3. 在开发者工具中导入项目，选择项目根目录
4. AppID 填写自己的测试号（或点击"使用测试号"）
5. 编译运行

### 关于 AppID（真实 appid 不入库）

`project.config.json` 中的 `appid` 固定为 `touristappid`（游客态），仓库**不存放真实 AppID**。在开发者工具里填写自己的 AppID 后，工具会把它写回这个文件，为避免误提交、泄露真实 AppID，建议在本机对该文件加标记：

```bash
git update-index --skip-worktree project.config.json   # 加标记（撤销：--no-skip-worktree）
```

- 这是**本地**设置（存于 `.git/info/index`），不会随仓库分发 —— 换机器 / 重新 clone 后需再执行一次
- 加标记后 `git add` 会**静默忽略**该文件的改动；若确实要改它受版本控制的内容（如 `packOptions.ignore`），先撤销标记，改完提交后再加回来
- 个人编译设置存放于 `project.private.config.json`，该文件已在 `.gitignore` 中，不受影响

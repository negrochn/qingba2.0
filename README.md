# 庆爸听力线 2.0

一个帮助家长记录孩子英语听力训练打卡进度的小程序，基于「庆爸听力线 常规路径（2.0版）」路线设计。

> **v3.0.0 全新布局**：设置页与全部选择类交互重构为微信原生分组列表 + 整页单选（原语3）风格，统一配色、字号、间距与深色模式适配，并沉淀为 `ui-design-spec` 设计规范。

## 功能概览

### 首页（打卡概览）

- 阶段 Hero 卡：展示当前阶段、进度条、已投入/目标时长
- 今日状态条：今日打卡分钟数与次数，一键跳转打卡
- 阶段统计 2×2 网格：阶段累计时长、已读完次数、本周时长、打卡天数
- 分组时长分布：主线绘本/主线分级/动画/辅线/拓展/APP 等分组累计占比
- 今日打卡明细：展示今日打卡记录，支持左滑删除

### 路线

- 7 个阶段可视化路线图：常规 1-6 阶段 + 准桥梁阶段
- 当前阶段可打卡，已完成阶段显示绿色 ✓，未解锁阶段显示 🔒
- 首次进入小程序通过引导设置当前阶段；未设置当前阶段时所有阶段均锁定
- 点击阶段进入详情页，查看该阶段的资源列表

### 阶段详情

- 展示阶段内所有绘本/动画/音频资源，按 8 个分组展示，支持折叠
- 点击资源打开打卡弹窗，记录学习时长与备注
- 「已读完」按钮标记资源完成次数
- **阶段晋级**：当前常规阶段展示投入进度，时间达标后可申请晋级；开启「小小优趣计划」时需输入测试结果达到目标 phase 才能晋级

### 打卡记录

- 按年/月筛选查看历史打卡记录
- 展示阶段、分组、时长、备注等信息
- 支持左滑删除

### 我的

- 关于庆爸2.0、打卡记录、设置入口

### 设置

设置页采用微信原生分组列表风格，所有选择类入口统一跳转整页单选页（原语3）。

- **显示**
  - 字体大小：小 / 标准 / 大 / 特大四档，整页单选（原语3）切换，全站正文即时缩放（40rpx 以下的正文类字号生效，超大标题与装饰元素保持不变）
  - 深色模式：跟随系统 / 浅色 / 深色 三态，整页单选（原语3）切换，全站页面背景、卡片、文字、导航栏与 tabBar 自动适配
- **学习计划**
  - 小小优趣成长计划：开启后完成阶段需校验测试结果
- **数据管理**
  - 导出备份：一键生成 .docx（Word）备份文件并打开预览
  - 导入备份：整页单选（原语3）选择导入方式（覆盖式 / 合并式）后，从微信聊天选择备份文件恢复，支持 txt / json / docx
  - 清空数据：整页单选（原语3）选择清空范围（全部数据 / 常规1-6 / 准桥梁），二次确认后执行
- **开发者工具（仅开发版）**
  - 当前阶段：整页单选（原语3）选择/修改当前学习阶段；切换时该阶段之前的所有阶段自动标记为已完成
  - 压力测试：按真实计划生成测试数据（每阶段约 80-90 小时）
- **关于**
  - 关于小程序：显示「版本 X.X.X」
  - 数据存储：本地存储

## 技术栈

- **框架**：微信小程序原生开发
- **数据存储**：wx.getStorageSync / wx.setStorageSync（按月分片存储，含存储空间预警）
- **文件操作**：wx.getFileSystemManager / wx.openDocument

## 路线数据

路线基于「庆爸听力线 常规路径（2.0版）」，适用于 3-4 岁儿童英语听力训练，共 7 个阶段：

| 阶段 | 时间投入建议 | 准入标准 |
|------|-------------|---------|
| 常规一 | 60-80H | 零基础 |
| 常规二 | 60-80H | phase5 |
| 常规三 | 60-80H | phase8 |
| 常规四 | 60H | phase12 |
| 常规五 | 60H | phase14 |
| 常规六 | 60H | phase16 |
| 准桥梁 | 80-100H | 佩奇可初步裸听 |

## 本地开发

1. 安装 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)
2. 克隆本仓库
3. 在开发者工具中导入项目，选择项目根目录
4. AppID 填写自己的测试号（或点击"使用测试号"）
5. 编译运行
